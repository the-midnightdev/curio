# Curio

Editorial microlearning and intellectual discovery. Next.js, TypeScript, and Tailwind CSS. Content lives in local JSON files — no database, auth, or paid APIs.

## Scripts

```bash
npm run dev
npm run build
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Add a reading

Create `content/articles/your-slug.json` using the existing article files as a template. It will appear in the library, its field, and the curiosity index.
